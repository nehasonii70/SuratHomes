# SuratHomes 🏠

SuratHomes is a responsive real estate website designed for exploring residential and commercial properties in Surat. The website allows users to browse properties, explore projects, view agents, and find information related to buying and renting properties.

This project was developed as a frontend web development project with a focus on responsive design, clean UI, and user-friendly navigation.

## Features

- Responsive real estate website
- Property listings for buying and renting
- Property details page
- Real estate projects section
- Agent listings and profiles
- Property search and filtering interface
- Home loan EMI calculator
- Buying guide
- Rental information and tenant checklist
- FAQ section
- Contact and site visit enquiry forms
- Locality-based property exploration
- Responsive navigation
- Interactive buttons, forms, and UI components
- WhatsApp contact links
- Google Maps location links

How to Run

SuratHomes is a frontend project and does not require a backend server or database.

Method 1: Open Directly
Download or clone this repository.
Open the project folder.
Double-click on index.html.
The website will open in your default web browser.
Method 2: Using VS Code

For a better development experience, you can use Visual Studio Code with the Live Server extension.

Clone or download the repository.
Open the SuratHomes folder in VS Code.
Install the Live Server extension.
Right-click on index.html.
Select Open with Live Server.
The website will open in your browser.
How to Use the Website
1. Home Page

Start from the homepage to get an overview of the available properties, projects, and services.

Use the navigation bar to move between different sections of the website.

2. Browse Properties

Go to the Properties page to explore available properties.

Users can view information such as:

Property type
Location
Price
Area
Bedrooms
Bathrooms
Amenities

Click on a property to view more detailed information.

3. Buy a Property

The Buy page provides information about the property buying process.

It also includes an EMI calculator that can be used to get an approximate idea of monthly loan payments.

4. Rent a Property

The Rent page allows users to explore rental properties and provides useful information for tenants.

5. Explore Projects

The Projects page displays new and upcoming real estate projects with basic information about each project.

6. Find an Agent

Go to the Agents page to view available real estate agents.

Selecting an agent opens their profile page where users can view additional information and contact options.

7. Contact / Site Visit

Users can visit the Contact page to submit an enquiry or request a property site visit.

Contact options such as WhatsApp and location links are also provided where available.

8. FAQ

The FAQ page provides answers to common questions related to properties, buying, renting, and the services provided by the website.
